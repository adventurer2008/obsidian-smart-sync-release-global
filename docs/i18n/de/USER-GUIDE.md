<h1 id="smart-sync-user-guide">Smart Sync-Benutzerhandbuch</h1>
<p>Gilt für Smart Sync (<code>smart-sync-global</code>). <a href="https://smartsync.cc/de/">Website</a> · <a href="https://smartsync.cc/de/download/">Downloads</a> · <a href="https://smartsync.cc/de/privacy/">Privatsphäre</a>.</p>
<h2 id="install-or-update">Installieren oder aktualisieren</h2>
<p>Verwenden Sie Obsidian <strong>1.12.7 oder neuer</strong>.</p>
<h3 id="install-from-obsidian-community-plugins">Über die Community-Plugins von Obsidian installieren</h3>
<p>Sobald Smart Sync im Community-Verzeichnis von Obsidian gelistet ist, können Sie es direkt in Obsidian installieren:</p>
<ol>
<li>Öffnen Sie in Obsidian Einstellungen → Community-Plugins.</li>
<li>Falls Community-Plugins deaktiviert sind, aktivieren Sie diese und lesen Sie den Hinweis von Obsidian.</li>
<li>Wählen Sie Durchsuchen, suchen Sie nach Smart Sync und öffnen Sie den Eintrag (Autor: lihy).</li>
<li>Wählen Sie Installieren und anschließend Aktivieren.</li>
</ol>
<h3 id="wujie-hub-or-manual-download">Wujie Hub oder manueller Download</h3>
<p>Wählen Sie in Wujie Hub <strong>Smart Sync → Stabil</strong> für die aktuelle stabile Ausgabe.</p>
<p>Für die manuelle Installation laden Sie es herunter <code>main.js</code>, <code>manifest.json</code> und <code>styles.css</code> aus dem Matching <a href="https://github.com/adventurer2008/obsidian-smart-sync-release-global/releases">GitHub-Version</a>. Überprüfen Sie es <code>SHA256SUMS.txt</code>. Legen Sie die drei Dateien ein <code>&lt;vault&gt;/.obsidian/plugins/smart-sync-global/</code> (oder den Ihres benutzerdefinierten Konfigurationsordners <code>plugins/smart-sync-global/</code>). Laden Sie Obsidian neu und aktivieren Sie dann Smart Sync in den Community-Plugins, nachdem Sie selbst die Vertrauensaufforderung des Hosts überprüft haben.</p>
<p>Für ein Update das Plugin deaktivieren, ersetzen <strong>nur diese drei Programmdateien</strong>, dann neu laden und aktivieren. Bewahren <code>data.json</code>, geheimer Speicher, Synchronisierungskontrollpunkte und alle Notizen. Kopieren Sie nicht die Plugin-Einstellungen oder Anmeldeinformationen eines anderen Geräts in diesen Tresor. Behalten Sie die vorherigen Programmdateien und ein unabhängiges Backup; Durch das Herabstufen von Programmdateien können Cloud-Löschungen oder andere abgeschlossene Cloud-Vorgänge nicht rückgängig gemacht werden. Führen Sie nicht mehrere Synchronisierungsanbieter im selben Tresor aus, ohne deren Interaktionen aufzulösen.</p>
<h2 id="sign-in-and-connect-your-first-vault">Melden Sie sich an und verbinden Sie Ihren ersten Tresor</h2>
<ol>
<li>Offen <strong>Einstellungen → Smart Sync → Anmelden</strong>. Wählen Sie Google, GitHub oder E-Mail. Für die soziale Anmeldung wird der Systembrowser verwendet. Die E-Mail-Verifizierung verwendet einen kurzlebigen Code im Plugin-Dialog.</li>
<li>Kehren Sie nach der Autorisierung zu Obsidian zurück. Automatische Prüfungen werden nach einem vorübergehenden Netzwerkausfall oder nach der Rückkehr zur App fortgesetzt. Wenn Sie immer noch warten, verwenden Sie <strong>Überprüfen Sie die Anmeldung</strong> im ausstehenden Dialog. Wenn die Anfrage abläuft, öffnen Sie „Anmelden“ erneut. Geben Sie niemals einen Anmeldecode weiter.</li>
<li>Erstellen Sie einen Cloud-Tresor oder wählen Sie einen vorhandenen Tresor aus und befolgen Sie dann die Eingabeaufforderung für die Verschlüsselungs-Passphrase. Bewahren Sie die Passphrase sicher auf: Eine Kontoanmeldung kann sie nicht wiederherstellen. Ein übereinstimmender Tresorname allein identifiziert nicht denselben Cloud-Tresor.</li>
<li>Überprüfen Sie die Synchronisierungsrichtung, Anhang-Downloads, Ausschlüsse und Konfigurationsumfang, bevor Sie vorhandene Dateien synchronisieren.</li>
<li>Lauf <strong>Notebook jetzt synchronisieren</strong>, öffnen <strong>Synchronisieren Sie Aufgaben und Verlauf</strong>, und warten Sie auf den Abschluss. Überprüfen Sie repräsentative Hinweise, Anhänge und Original-Änderungszeiten, bevor Sie ein anderes Gerät anschließen.</li>
</ol>
<p>Wenn eine Antwort zur Tresorerstellung verloren geht, verwenden Sie die Wiederherstellungsnachricht des ausstehenden Vorgangs und überprüfen Sie die vorhandenen Cloud-Tresore. Erstellen Sie nicht wiederholt neue Tresore mit unterschiedlichen Namen.</p>
<h2 id="add-another-device">Fügen Sie ein weiteres Gerät hinzu</h2>
<p>Installieren Sie dasselbe regionale Plugin, melden Sie sich bei demselben Konto an und wählen Sie denselben Cloud-Tresor aus. Verwenden Sie die ursprüngliche Verschlüsselungspassphrase. Der Geräteverwaltungsablauf bietet auch einen sechsstelligen Kopplungscode: Holen Sie ihn auf dem neuen Gerät ab und genehmigen Sie ihn über ein bereits verbundenes Gerät <strong>Gerät hinzufügen</strong>, und vergleichen Sie den angezeigten Fingerabdruck vor der Genehmigung. Fügen Sie führende Nullen ein. Abgelaufene oder verwendete Codes müssen neu generiert werden.</p>
<p>Überprüfen Sie die lokalen Filter und Anhangsrichtlinien jedes Geräts. Wenn der Cloud-Upload auf einem Gerät abgeschlossen wird, bedeutet das nicht, dass ihn auch alle anderen Geräte heruntergeladen haben.</p>
<h2 id="synchronization-attachments-and-offline-recovery">Synchronisierung, Anhänge und Offline-Wiederherstellung</h2>
<p>Verwenden Sie für die normale Bearbeitung die bidirektionale Synchronisierung. Die Modi „Nur Hochladen“, „Nur Empfangen“, „Vorhandenes aktualisieren“ und „Pause“ schränken bewusst ein, welche Änderungen verschoben werden. Lesen Sie die Richtungsaufforderung, bevor Sie den Modus wechseln. Wenn Sie eine Runde stoppen, wird die automatische Synchronisierung angehalten, bis Sie eine Auswahl treffen <strong>Jetzt synchronisieren</strong> oder <strong>Versuchen Sie es noch einmal</strong>.</p>
<p>Markdown-Notizen haben bei vollständigen und inkrementellen Körperübertragungen Vorrang vor Anhängen. Verzeichnis-, Umbenennungs- und Löschabhängigkeiten behalten weiterhin ihre sichere Reihenfolge bei, und eine aktive Übertragung kann vor neu in die Warteschlange gestellten Notizen abgeschlossen werden. Eingebettete Bilder oder PDFs können später eintreffen. Wählen Sie in den Synchronisierungseinstellungen die Richtlinie zum Herunterladen von Anhängen aus. verwenden <strong>Ausstehende Anhänge herunterladen</strong> wenn nötig. Die Überprüfung der Metadaten und die Netzwerkbedingungen wirken sich weiterhin auf die Gesamtzeit aus.</p>
<p>Lokale Änderungen bleiben auch offline lokal. Wenn das Netzwerk wiederhergestellt ist, öffnen Sie Obsidian erneut, setzen Sie die Synchronisierung fort, falls sie angehalten wurde, und überprüfen Sie die verbleibenden Aufgaben. Lassen Sie Obsidian auf Telefonen und Tablets im Vordergrund, bis wichtige Änderungen abgeschlossen sind. Wenn Sie den Bildschirm sperren oder die App in den Hintergrund schalten, kann sie angehalten werden. Die Desktop-Tray-Einstellungen ermöglichen keine Ausführung im mobilen Hintergrund.</p>
<p>Die Synchronisierung überträgt die ursprüngliche Änderungszeit der Quelldatei, wenn diese Metadaten verfügbar sind. Bei einer alten Cloud-Revision, bei der diese fehlt, kann nicht davon ausgegangen werden, dass sie die ursprüngliche Zeit bewahrt hat. von einer Quelle neu synchronisieren, die es beibehält. Eine Zusammenführung, die neuen Inhalt erzeugt, hat eine neue Änderungszeit.</p>
<p>LAN-Beschleunigung ist optional. Überprüfen Sie den Verbindungsstatus. Wenn direkte Verbindungen nicht unterstützt werden oder kein Peer verfügbar ist, bleibt die Cloud-Synchronisierung der Fallback. Die Erkennung im selben Netzwerk ist keine Garantie dafür, dass eine direkte Verbindung funktioniert.</p>
<h2 id="recover-earlier-versions-and-deleted-notes">Stellen Sie frühere Versionen und gelöschte Notizen wieder her</h2>
<p>Öffnen Sie eine synchronisierte Notiz und wählen Sie <strong>Notizverlauf anzeigen und wiederherstellen</strong> aus dem Kontextmenü, oder <strong>Aktiven Notizverlauf anzeigen</strong> aus der Befehlspalette. Überprüfen Sie vor der Wiederherstellung die Revision und die Unterschiede. Benutzen <strong>Gelöschte Notizen anzeigen</strong> um wiederherstellbare gelöschte Inhalte zu überprüfen. Die Verfügbarkeit hängt von der Aufbewahrungsrichtlinie des Tresors ab. Der abgelaufene oder gelöschte Verlauf kann nicht wiederhergestellt werden.</p>
<p>Benutzen <strong>Aufbewahrung, Nutzung und Bereinigung</strong> um die Verlaufsrichtlinien und die Cloud-Nutzung zu überprüfen. Durch Bereinigungs- und Löschaktionen wird der berechtigte Verlauf dauerhaft entfernt. Sichern Sie zuerst und lesen Sie die Bestätigung. Der Verlauf ist kein Ersatz für ein unabhängiges Backup.</p>
<h2 id="sync-selected-obsidian-settings">Ausgewählte Obsidian-Einstellungen synchronisieren</h2>
<p>Erweitern Sie die Synchronisierungseinstellungen und die Konfigurationskategorien. Editor-Einstellungen, Erscheinungsbild, Hotkeys, Lesezeichen, Community-Plugin-Code, Plugin-Daten, Plugin-Aktivierung, Themen und Snippets verfügen über separate Steuerelemente. Überprüfen Sie einzelne Ausschlüsse, bevor Sie eine Kategorie aktivieren. Änderungen an der Plugin-Aktivierung können einen Neustart von Obsidian erfordern. Nur Desktop-Plugins werden auf Mobilgeräten übersprungen; Überprüfen Sie die Kompatibilität von Drittanbieter-Plugins, bevor Sie deren Code oder Daten dort aktivieren.</p>
<p>Filtervoreinstellungen wenden die Ausschlüsse, den Anhangsschwellenwert und den Konfigurationsbereich dieses Geräts an. Wenn Sie eins anwenden, wird die Synchronisierung angehalten. Überprüfen Sie es und nehmen Sie es explizit wieder auf. Voreinstellungen kopieren keine Kontoschlüssel und binden keinen anderen Cloud-Tresor. Benutzen <strong>Exportieren Sie die verschlüsselte Konfigurationswiederherstellung</strong> für eine geschützte Wiederherstellung und speichern Sie das Passwort separat; Geben Sie niemals die Wiederherstellungsdatei und das Passwort gemeinsam weiter.</p>
<h2 id="sorting-pins-recent-files-and-search">Sortierung, Pins, aktuelle Dateien und Suche</h2>
<p>Aktivieren Sie die Sortierung und legen Sie die Stammregel fest. Tiefere Ebenen können die übergeordnete Regel erben oder eine benutzerdefinierte Regel verwenden. Verwenden Sie dazu das Kontextmenü einer Notiz <strong>Pin</strong>, <strong>Lösen</strong>, <strong>Nach unten bewegen</strong> oder <strong>Von unten entfernen</strong>. Pin-Änderungen warten auf die Synchronisierung, um andere Geräte zu erreichen.</p>
<p>Aktivieren Sie aktuelle Dateien, um die Registerkarte „Uhr“ in der linken Seitenleiste zu verwenden <strong>Aktuelle Dateien</strong> Befehl; Durch die Deaktivierung wird die Aufzeichnung geöffneter Dateien gestoppt. Aktivieren Sie die Notizsuche, um lokal verfügbare Notizen zu durchsuchen. Anhänge, die nicht heruntergeladen wurden, sind keine lokal verfügbaren Inhalte.</p>
<h2 id="password-protect-a-note-or-selected-text">Schützen Sie eine Notiz oder einen ausgewählten Text mit einem Passwort</h2>
<p>Öffnen Sie eine Markdown-Notiz, wählen Sie bei Bedarf Text im Bearbeitungsmodus aus und führen Sie ihn dann aus <strong>Ausgewählten Text verschlüsseln</strong> oder <strong>Gesamte Notiz verschlüsseln</strong>. Legen Sie ein separates Passwort fest, bestätigen Sie es, lesen Sie die Warnung und speichern Sie es. Klicken Sie auf den verschlüsselten Inhalt, um ihn zu entsperren. Zu seinen Aktionen gehören <strong>Bearbeiten</strong>, <strong>Sperren</strong>, <strong>Passwort ändern</strong> und <strong>Dauerhaft entschlüsseln</strong>. Bearbeiten Sie über das sichere Bearbeitungsfenster, damit die Speicherungen verschlüsselt bleiben.</p>
<p>Titel bleiben sichtbar. Verlinkte Bilder und Anhänge werden nicht automatisch mit dem ausgewählten Text verschlüsselt. Frühere Verlaufsdaten und Backups enthalten möglicherweise Klartext. Bei der permanenten Entschlüsselung wird gewöhnlicher Klartext lokal geschrieben und normal synchronisiert. Passworthinweise werden nicht verschlüsselt. Passwörter können nicht wiederhergestellt werden.</p>
<p>Benutzen <strong>Beachten Sie die Verschlüsselungseinstellungen</strong> um das Zeitlimit für die Inaktivitätssperre auszuwählen, oder <strong>Sperren Sie jetzt alle verschlüsselten Inhalte</strong>. Auch das Schließen der Notiz, das Verlassen des Tresors oder das Verschieben der App in den Hintergrund sperrt sie. Wenn das Speichern fehlschlägt, folgen Sie den Anweisungen <strong>Stellen Sie verschlüsselte Entwürfe wieder her</strong> um eine separate verschlüsselte Notiz mit dem ursprünglichen Passwort wiederherzustellen; Löschen Sie nicht das Original, um den Fehler zu beheben.</p>
<h2 id="desktop-tray-and-windows-startup">Desktop-Tray und Windows-Start</h2>
<p>Auf unterstützten Desktop-Hosts <strong>Erweitert → Im Hintergrund mit Taskleistensymbol ausführen</strong> ist standardmäßig aktiviert. Wenn Sie das Tresorfenster schließen, läuft es weiter. Klicken Sie auf das Taskleistensymbol, um es wiederherzustellen. Das Menü kann nur diesen Tresor schließen. Nicht unterstützte Tray-Hosts behalten das normale Schließen bei. Mobile verbirgt diese Option.</p>
<p><strong>Beim Anmelden in die Taskleiste starten</strong> ist nur für Windows gültig und standardmäßig deaktiviert. Durch die Aktivierung wird die Verknüpfung dieses Tresors im Startordner des aktuellen Benutzers erstellt und die Hintergrundleiste aktiviert. Gewöhnliche Starts bleiben sichtbar. Benutzerdefinierte Obsidian-Profile können den Start nicht ermöglichen, da der Host Anforderungen möglicherweise an eine andere Instanz weiterleitet. Deaktivieren Sie den Login-Start, bevor Sie die Taskleiste deaktivieren, deinstallieren oder auf eine Version ohne Startunterstützung zurückgreifen. macOS, Linux, Android, iPhone und iPad zeigen den Startschalter Windows nicht an.</p>
<h2 id="storage-plans-and-payments">Lagerpläne und Zahlungen</h2>
<p>Öffnen Sie den Speichertarif in den Einstellungen, um Ihren aktuellen Tarif anzuzeigen. Auf Mobilgeräten wird versucht, den Systembrowser direkt zu öffnen. Verwenden Sie den angebotenen Link, wenn die Weiterleitung fehlschlägt oder nicht bestätigt werden kann. Prüfen Sie vor der Zahlung Betrag, Währung, Abrechnungszeitraum und Verlängerungsbedingungen. Die Abrechnung erfolgt in USD über den Ihrem Konto zugewiesenen Zahlungsanbieter: standardmäßig Stripe, bei berechtigten Konten auch Dodo Payments. Beim erneuten Öffnen eines unbezahlten Kaufs wird die ursprüngliche Bestellung fortgesetzt. Bestehende Bestellungen und Abonnements behalten ihren Zahlungsanbieter. Zahlen Sie bei unklarem Ergebnis nicht erneut. Kehren Sie zu Obsidian zurück und prüfen Sie die Tarifaktualisierung. Prüfen Sie eine Bestellung mit unklarem Status, bevor Sie erneut bezahlen.</p>
<p>Der kostenlose Plan umfasst 50 MB, einen Cloud-Tresor und unbegrenzte Geräte. Bezahlte Kapazitäten und aktuelle Konditionen finden Sie auf der <a href="https://smartsync.cc/de/pricing/">Seite „Pläne“.</a>. Der Speicherplatz wird von allen Cloud-Tresoren des Kontos gemeinsam genutzt.</p>
<h2 id="sign-out-revoke-a-device-or-delete-an-account">Melden Sie sich ab, sperren Sie ein Gerät oder löschen Sie ein Konto</h2>
<p>Beim Abmelden bleiben lokale Notizen erhalten. Wenn die Offline-Abmeldung die Remote-Sperrung nicht bestätigen kann, sperren Sie das Gerät von einem anderen verbundenen Gerät, wenn eine sofortige Entfernung erforderlich ist. Durch die Deinstallation wird das Cloud-Konto nicht gelöscht.</p>
<p>Das Löschen aus der Cloud ist destruktiv: Überprüfen Sie zunächst ein unabhängiges lokales Backup. Löschen Sie Cloud-Tresore über die Tresorverwaltung und warten Sie auf die Bereinigung. Offen <strong>Konto → Gefahrenzone → Konto löschen</strong>, bestätigen Sie dasselbe Konto, wenn Sie dazu aufgefordert werden, und geben Sie Folgendes ein <strong>DELETE</strong> genau. Bezahlte Dienstzeit steht der Löschung nicht entgegen. Dadurch werden der Kontozugriff und die damit verbundenen Identitäten entfernt. Lokale Notizen bleiben erhalten. Lesen Sie die <a href="https://smartsync.cc/de/privacy/">Aufbewahrungsrichtlinie</a>.</p>
<h2 id="troubleshooting-and-device-limits">Fehlerbehebung und Gerätegrenzen</h2>
<p>Lesen Sie die mit dem Fehler angezeigte Wiederherstellungsaktion. Bei einem Geräte- oder Tresorlimit können Sie einen vorhandenen Tresor verbinden, ein ungenutztes Gerät widerrufen oder einen geeigneten Plan auswählen. Exportieren Sie Diagnosen manuell, wenn der Support sie benötigt. Der globale Client lädt keine diagnostischen Telemetriedaten hoch. Senden Sie den sichtbaren Fehler, die Plugin-/Obsidian-Versionen und die Plattform an <a href="mailto:admin@smartsync.cc">admin@smartsync.cc</a>. Entfernen Sie Passwörter, Token, Bestätigungscodes und private Notizinhalte.</p>
<h2 id="interface-language">Schnittstellensprache</h2>
<p>Diese Version unterstützt Englisch, vereinfachtes und traditionelles Chinesisch, Japanisch, Koreanisch, Deutsch, Französisch, Spanisch, brasilianisches Portugiesisch und Russisch.</p>
<p>Wählen Sie Obsidian folgen oder eine explizite Sprache in der Benutzeroberflächensprache oben in den Smart Sync-Einstellungen. Die Auswahl gilt nur für diesen lokalen Tresor auf diesem Gerät. Speichern Sie es, beenden Sie alle aktiven Synchronisierungen, laden Sie dann das Plugin neu oder starten Sie Obsidian neu, um Einstellungen, Befehle und Menüs gemeinsam zu aktualisieren.</p>
<p>Dadurch wird nur der Anzeigetext geändert. Dienstregion, Konten, Cloud-Tresore, Verschlüsselungskennwörter, Dateiinhalte und Synchronisierungsfortschritt ändern sich nicht. Verschiedene Geräte können unterschiedliche Sprachen verwenden.</p>
