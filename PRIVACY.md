# Smart Sync privacy

The current Global [privacy policy](https://smartsync.cc/privacy/) describes account identity, operational metadata, encrypted vault data and third-party providers. Read it before using the service. The [terms](https://smartsync.cc/terms/) cover subscriptions and support refunds. Contact admin@smartsync.cc for privacy questions.

Note content and paths are encrypted on the device before upload. Account identity, vault/device labels, usage, connection information and payment records are outside that content-encryption boundary. Google/GitHub sign-in requests identity and email, not note content, Gmail messages, Drive files or repository content. Stripe handles payment details. Content encryption does not replace device security or independent backups.

This source preview does not include credentials, user databases or populated vaults.
